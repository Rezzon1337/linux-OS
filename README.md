# GNU/Linux
==== Дистрибутивы GNU/linux ====
Дистрибутивы GNU/linux - это готовая OS на базе linux утилит GNU и дополнительного ПО для пользователя.
linux - ядро которое связывает железо с программами, это и есть дистрибутив.
GNU - это unix-OS, в которой есть базовый набор программ, утилит и лицензий, 
Популярные дистрибутивы - ubuntu, mint, debian, arch, kali, red hat и тд.
В составе дистрибутива - linux, утилиты GNU, интерфейс и пакеты.

==== Структура Inode ====
Структура Inode - это структура данных в файловой системе linux, она хранит метаданные о файлах, а точнее тип файла, доступ к перезаписи, путь, размер.

==== Шаги запуска виртуальной среды ====
Открыть программу Oracle VirtualBox --> нажать на кнопку "создать" виртуальную машину --> Обязательно ввести имя среды, а также выбрать ISO образ, нажать кнопку "далее" --> написать имя хоста в строке "Имя хоста:", нажать на кнопку "далее" --> выделить ресурсы виртуальной машине по базе (4096 RAM и половину от всех ядер ЦП) --> выделить память с жесткого диска (25GB).
